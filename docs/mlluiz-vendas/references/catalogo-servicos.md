**Atenção:** este arquivo é um molde. Preços, prazos, entregas e garantias **não estão preenchidos de propósito**, porque o agente não pode inventar nada comercial. Em conversa, esses dados vêm sempre de `buscar_informacoes`. Se quiser, preencha os campos `[PREENCHER]` com a informação oficial para servir de apoio na hora de recomendar.

## Como o agente usa este catálogo
- Recomendar com base na dor confirmada (uma solução principal, no máximo uma alternativa).
- Traduzir o serviço em benefício prático para o cliente.
- Nunca citar valor, prazo, garantia ou escopo sem confirmar na base.
